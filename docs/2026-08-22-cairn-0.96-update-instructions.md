# Update to cairn 0.96.0 (the floors release)

Written 2026-08-22 from this repo's `package.json` as it stands. Starting point: cairn
`^0.95.0`, `@sveltejs/kit ^2.12`, `svelte ^5.56.3`, `@cloudflare/workers-types ^4.20260405.1`,
`wrangler ^4.93.1`, `engines.node >=22`, Tidy enabled, CI on Node 24.

## Steps for this site

1. In `package.json`: `@glw907/cairn-cms` to `^0.96.0`; `@sveltejs/kit` to `^2.70`; `svelte` to
   `^5.56.10`; `@cloudflare/workers-types` to `^5`; `wrangler` to `^4.125.0` (the new
   `compatibility_date` needs a workerd at least `1.20260815`); `engines.node` to `>=24`.
2. `@cloudflare/workers-types` moves from 4 to 5. Its global `Buffer: any` shadows
   `Buffer.toString(encoding)` in any file that also loads `@types/node`; if `npm run check`
   goes red on a `Buffer` call, switch that call to `TextDecoder`, the way cairn's own scripts
   did.
3. Tidy is enabled here with no explicit `tidy.model`, so it moves to `claude-sonnet-5`. Nothing
   to change; confirm one Tidy run after deploy.
4. Delete `package-lock.json`, run `npm install` in a clean clone, commit the lockfile.

## What 0.96.0 requires of every site

cairn 0.96.0 raises its floors to the versions it develops and tests against. Three changes
need an action; the rest of the window is additive. The full list is the `0.96.0` entry in
cairn's `docs/extend/migration-notes.md`, and the exact targets live on its
`docs/reference/supported-toolchain.md`.

1. Node 24 or later on every machine and runner that installs or builds the site. `npm install`
   only warns on an older Node; `create-cairn-site`'s preflight refuses it.
2. `@sveltejs/kit ^2.70` and `svelte ^5.56.10` in `devDependencies` before installing. npm's
   default peer resolution refuses the install otherwise.
3. `@cloudflare/workers-types ^5` in `devDependencies`. A site on `wrangler types` still needs
   it, because cairn's declarations import from it; without it every cairn-typed binding
   silently becomes `any` under `skipLibCheck`.

Two conditional items. A hand-rolled `TidyClient` fake must tolerate an optional
`output_config` field. A site that added a wrangler `alias` for `$app/environment` to bundle
the `./sveltekit` barrel outside Vite can remove it; the barrel's only `$app` import is now a
guarded dynamic import.

Two behavior changes to know about. Tidy's default model is `claude-sonnet-5` at low effort; a
site that sets `tidy.model` keeps its choice. `previewLoad` now strips `canonical`, `og:url`,
and `jsonLd.url` from a preview render's `seo`, so a site that stripped them itself can drop
that code.

## Verify

Run `npm ci` from a clean clone (it must not print a peer or engine warning), then `npm run
check`, `npm run build`, and the site's deploy dry run. A green build with a stale lockfile
proves nothing: regenerate the lockfile so it resolves from the registry.
